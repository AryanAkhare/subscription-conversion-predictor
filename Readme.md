# Subscription Conversion Predictor

## Overview
This project aims to improve marketing ROI in the financial sector by predicting which clients are most likely to subscribe to term deposits.  
Using machine learning, it shifts the approach from mass marketing to precision targeting — saving time, effort, and resources.

---

## Features
- Predicts client likelihood of term deposit subscription  
- Data-driven decision support for marketing teams  
- Reduces cost and improves campaign efficiency  
- Built with Python, Streamlit, and scikit-learn  

---

## Installation

   ```bash

2.Create and activate a virtual environment:
python -m venv venv

Run the Streamlit app locally:
